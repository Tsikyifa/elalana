# Legacy templates

Ce dossier contient les anciens templates Django conservés uniquement pour la transition de migration vers une architecture React-first.

- Les vues HTML legacy sont archivées ici pour éviter de les mélanger avec le backend API.
- La logique métier et les endpoints REST doivent être consommés par le frontend React.
- Ce dossier doit être supprimé ou migré vers un autre système de rendu uniquement après la fin de la migration UI.
